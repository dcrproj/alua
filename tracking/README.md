## Vision du produit

Créer la référence française de consultation des données immobilières publiques :
une carte interactive enrichie + des milliers de fiches SEO (adresses, parcelles, communes, EPCI)
agrégant cadastre, DVF, DPE, PLU, risques et patrimoine.

**Phase 1 — Plateforme grand public** (contenu + carte + publicité)  
**Phase 2 — API B2B** (monétisation des données agrégées et historisées)
